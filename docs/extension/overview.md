# Ares-IQ Python Extensions

The Ares-IQ extensions are Python modules written in C++ and exported as Python bindings. These are written for
a few reasons which include, but are not limited to performance reasons and compatability. To contribute to the
extension library, please read the style/standards before proceeding, and if you find yourself stuck on something,
then it is worth reading the contribution tips document to see if a similar problem was solved previously.
